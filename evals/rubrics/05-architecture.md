# Rubric: Architecture

- ARC-01 | 3 | There is a context diagram and a component table with responsibilities and data ownership.
- ARC-02 | 3 | Every significant decision links to an ADR with options considered and consequences.
- ARC-03 | 3 | Data flows match the API contract and data model exactly (no component or endpoint that is not in them).
- ARC-04 | 2 | The file or repository structure is realistic (no phantom directories) and each part has a purpose.
- ARC-05 | 2 | Every dependency or technology has a stated purpose, and choices respect the constitution constraints.
- ARC-06 | 2 | Cross-cutting concerns are covered: authentication, configuration, logging, errors.
- ARC-07 | 2 | Deployment topology covers local development and at least one deployed environment.
- ARC-08 | 2 | Risks and trade-offs are stated honestly, with mitigations or accepted-risk notes.
- ARC-09 | 2 | Lifecycles in the architecture match the state machines in the data model.
