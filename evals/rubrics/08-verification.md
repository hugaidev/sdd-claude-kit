# Rubric: Verification Specification

- VER-01 | 3 | Every requirement has at least one test, and the traceability matrix shows it.
- VER-02 | 3 | Every API endpoint has a success test and tests for each documented error status.
- VER-03 | 3 | Each test case states preconditions, steps and an unambiguous expected result.
- VER-04 | 2 | There is an end-to-end walkthrough that covers every main workflow in the PRD.
- VER-05 | 2 | Non-functional requirements have verification with the measure and threshold from the PRD.
- VER-06 | 2 | UI behaviour, where there is a UI, is tested for the happy path and the error path.
- VER-07 | 2 | Exit criteria define exactly when the release gate passes.
- VER-08 | 1 | Test data and environments are specified and contain no real personal data.
