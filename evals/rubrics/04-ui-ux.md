# Rubric: UI/UX Specification

- UI-01 | 3 | Every screen the PRD implies has a defined purpose, layout (wireframe or description) and the requirements it serves.
- UI-02 | 3 | Every data view specifies loading, empty and error states.
- UI-03 | 2 | Every interactive element defines default, hover, focus and disabled states.
- UI-04 | 2 | Design tokens cover colour, typography, spacing, radii and elevation, with names and values.
- UI-05 | 2 | Responsive rules cover at least three breakpoints from phone to desktop.
- UI-06 | 2 | Accessibility targets a named standard and covers keyboard, focus order, contrast and reduced motion.
- UI-07 | 2 | Destructive actions require confirmation and say what will be lost.
- UI-08 | 3 | Every screen names the API endpoints it uses and they exist in the API contract.
