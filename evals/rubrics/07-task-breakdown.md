# Rubric: Task Breakdown

- TSK-01 | 3 | Every task is small enough to finish in about a day and is independently verifiable.
- TSK-02 | 3 | Every task has a concrete definition of done that a reviewer can check.
- TSK-03 | 3 | Every task traces to at least one requirement and one test.
- TSK-04 | 2 | A task can be understood and done without reading other tasks, apart from its listed dependencies.
- TSK-05 | 2 | Dependencies are explicit, acyclic, and show where tasks can run in parallel.
- TSK-06 | 2 | Tasks that change a spec are separate and marked as spec changes.
- TSK-07 | 2 | The set of tasks covers every requirement in the PRD with no unexplained extras.
