# Rubric: Implementation Plan

- PLN-01 | 3 | The first phase is a thin end-to-end slice (walking skeleton), not a layer built in isolation.
- PLN-02 | 3 | Each phase has a concrete deliverable and exit criteria that can be checked.
- PLN-03 | 3 | Every requirement is assigned to a phase.
- PLN-04 | 2 | Dependencies and sequencing are explicit, and parallel work is identified.
- PLN-05 | 2 | A risk table lists likelihood, impact and a mitigation for each risk.
- PLN-06 | 2 | Estimates are realistic and state their basis, not optimistic guesses.
- PLN-07 | 1 | Quality gates are defined per phase.
